# syncrig-updates

SyncRig Host 的 Sparkle 更新源。

- `appcast.xml`：更新描述，由 GitHub Pages 提供：https://joeysudoer.github.io/syncrig-updates/appcast.xml
- 安装包（DMG、ZIP、增量包）放在 [Releases](https://github.com/joeysudoer/syncrig-updates/releases)，每版一个 tag：`v<版本>-<构建号>`

首次安装请到 [最新 Release](https://github.com/joeysudoer/syncrig-updates/releases/latest) 下载 DMG。

发版在 SyncRig 仓库运行 `make mac-release`，不要手改这里的文件。
